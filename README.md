# Il viaggio di Mistral — Flipbook PWA

Flipbook di "A. Mor — Il viaggio di Mistral — Volevo insegnare Amore".
PWA installabile, ottimizzata per mobile verticale a pagina singola.

- `index.html` — flipbook (StPageFlip, stessi suoni/animazioni/interazioni dell'originale)
- `manifest.webmanifest` + `sw.js` — installabile e offline-first
- `assets/` — libreria flip + audio
- `pages/` — 212 pagine webp
- `icons/` — icone PWA generate da copertina

Desktop: doppia pagina. Mobile (≤700px): pagina singola verticale, footer impilato.
